Scaled Dot-Product Attention, Step by Step

Source: Attention Is All You Need · Vaswani et al. · 2017 — Section 3.2.1 · Eq. (1)

1 · Start here

Attention maps a query and a set of key-value pairs to an output. Each query is compared with every key by a dot product; after dividing by sqrt(d_k) and applying softmax, the resulting weights say how much of each value row to mix. The output row is the weighted average of the value rows.

Why it matters

This single formula is the core operation of the Transformer. The 1/sqrt(d_k) factor keeps the softmax in a well-behaved range so gradients do not vanish when the key dimension is large.

Symbols

Qmatrix of queries, one row per query position; shape n x d_k
Kmatrix of keys, one row per key position; shape m x d_k
Vmatrix of values, one row per key position; shape m x d_v
dkdimension of each query/key vector (number of columns of Q and K)
dvdimension of each value vector (number of columns of V)
QKTmatrix of raw similarity scores, shape n x m
dkscaling factor that counteracts the growth of dot-product variance
softmaxrow-wise normalization into non-negative weights summing to 1
Attention(Q,K,V)output matrix, shape n x d_v

How it works, step by step

  1. Form the raw scores S = QK^T: entry (i,j) is the dot product of query row i with key row j.
  2. Divide every score by sqrt(d_k) to get the scaled scores; this keeps their spread roughly constant as d_k grows.
  3. Apply softmax to each row of scaled scores, producing attention weights A whose rows are non-negative and sum to 1.
  4. Multiply A by V: output row i is the weighted average of the value rows, with weights A[i,:].
  5. Inspect the weights: equal scores give a uniform row, a dominant score gives a row concentrated on one value.

    3 · Guided explorations

    1

    Equal scores give uniform weights

    Change
    Set all three rows of K equal (as in the preset) so every key is identical.
    Observe
    Every score in row 1 is 2, the weights row becomes [0.333, 0.333, 0.333], and the output row is the plain average of the value rows, [0.667, 0.667].
    Why
    Softmax of equal scores is uniform, so the output is an unweighted average of V.
    2

    A dominant score concentrates attention

    Change
    Make query row 1 align with key row 1 (Q = [[2,0,0],[0,1,0]], K = [[2,0,0],[0,1,0],[0,0,1]]).
    Observe
    Row 1 scores are [4, 0, 0]; after scaling by sqrt(3) the weights are about [0.834, 0.083, 0.083], so the output row is close to v1 = [1, 0].
    Why
    A large positive score dominates the softmax, so that value row supplies most of the output.

    4 · Common misunderstanding

    The attention weights are not the output. They are a probability distribution over the value rows; the output is the weighted average A V. Also, scaling does not change the ranking of scores, only their spread, which is what keeps softmax from saturating.

    5 · Source grounding

    Paper: Attention Is All You Need · Vaswani et al. · 2017 — Section 3.2.1 · Eq. (1).

    From the paper

    • Attention maps a query and a set of key-value pairs to an output, where query, keys, values and output are all vectors (Section 3.2).
    • The output is a weighted sum of the values, with weights from a compatibility function of the query with each key (Section 3.2).
    • Scaled dot-product attention computes dot products of the query with all keys, divides each by sqrt(d_k), and applies softmax to obtain the weights on the values (Section 3.2.1).
    • Attention(Q,K,V) = softmax(QK^T/sqrt(d_k))V (Eq. 1).
    • Dot-product attention is identical to the algorithm except for the scaling factor 1/sqrt(d_k) (Section 3.2.1).
    • For large d_k the dot products grow large in magnitude, pushing softmax into regions with extremely small gradients; the paper scales by 1/sqrt(d_k) to counteract this (Section 3.2.1).
    “We compute the dot products of the query with all keys, divide each by dk , and apply a softmax function to obtain the weights on the values.”
    “To counteract this effect, we scale the dot products by 1dk .”

    Our simplifications & examples

    • We use tiny editable matrices (2 queries, 3 keys, d_k = 3, d_v = 2) instead of the paper's d_k = d_v = 64 and d_model = 512.
    • We show a single attention head, not the 8-head multi-head attention of Section 3.2.2.
    • The sweep over d_k is a toy illustration of the variance argument in footnote 1; it is not a paper experiment.
    • No training, masking, or positional encoding is included.
